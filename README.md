# ⚡ Dash Showdown 3D - Multiplayer Geometry Dash

A high-octane, arcade-grade **3D Geometry Dash** game running entirely in the browser with **real-time WebRTC Peer-to-Peer multiplayer**, authentic procedural EDM synthesizer music, and hilarious meme features!

---

## 🎮 Play With Friends on the Web (Multiplayer)

No servers or account logins required! Built with WebRTC peer-to-peer architecture:

1. **Host a Room**:
   - Open the game in any web browser.
   - Click the **`👥 INVITE FRIENDS`** button in the top bar.
   - Click **`📋 COPY INVITE LINK`** (e.g. `https://loismybro.github.io/dash-showdown/?room=DASH-4921`).
2. **Invite Friends**:
   - Send the copied link to your friends on **Discord, WhatsApp, Telegram, or iMessage**.
   - Your friends click the link on their phone, iPad, laptop, or PC to instantly join your room!
3. **Customize Your Tag & Cube**:
   - Enter your **Gamer Tag** (e.g. *Loismybro*, *SpeedDemon*).
   - Pick your favorite neon cube color (Mint Volt, Cyber Cyan, Hot Pink, Solar Gold, Neon Violet, Inferno Red).
4. **Launch the Synced Race**:
   - When everyone is in the lobby, click **`🚀 START RACE`**!
   - A synchronized **3.. 2.. 1.. GO!** countdown fires across all connected players' screens, and you race neck-and-neck in real time!

## 🤪 Hilarious Meme Chaos Features

- 🥁 **Tung Tung Sahur Ambush**:
  - Tung Tung pops in mid-run with his wooden mallet, scissoring running legs, and red headband!
  - Hammers the sulfur cube 6 times while shouting *"Tung tung tung sahur! Sahur sahur, tung tung tung sahur!"*
  - Cube squashes flat, face turns dizzy with comical tongue out, and floating comic text explodes (`💥 TUNG!`, `🔨 BONK!`, `🥁 SAHUR!`).
  - Tung Tung shouts *"SAHURRRRR! 🌙"* and blasts off into outer space!
- 🍄 **Smurf Cat ("We Live, We Love, We Lie") Repeat Death Intervention**:
  - When you crash **2 or more times at the exact same obstacle spot**, Shailushai / Smurf Cat descends to heal your soul!
  - Plays the iconic Alan Walker *The Spectre* melody with *"We live, we love, we lie"* vocals.
  - Grants `+10,000 AURA 🔥` and a celestial glowing cyan Smurf Cat halo orbiting your cube!
- 🗿 **"WHAT THE SIGMA?!" Near-Miss Spike Dodge**:
  - Barely skim within millimeters of a spike tip without crashing to trigger the viral voice clip and floating `WHAT THE SIGMA?! 🗿` comic text!
- 💥 **Chaos Death Sounds**:
  - Deaths in chaos mode randomly trigger ultra-deep 808 **Vine Booms** or falling **Metal Pipe** reverberating clangs!
- 📁 **Custom Audio Uploader**:
  - Upload your own downloaded meme `.mp3` files in the Meme Chaos Menu to replace sounds on the fly!

## 🚀 How to Host on GitHub Pages (100% Free)

1. Create a new repository on GitHub:
   👉 [github.com/new](https://github.com/new) named `dash-showdown` (or any name you like).
2. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/Loismybro/dash-showdown.git
   git branch -M main
   git push -u origin main
   ```
3. Enable GitHub Pages:
   - On GitHub, go to your repo **Settings** > **Pages** (in the left sidebar).
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select **Branch**: `main`, Folder: `/ (root)`, and click **Save**.
4. In about 30 seconds, your game is live at:
   👉 `https://loismybro.github.io/dash-showdown/`
   Send the link to friends and play together anytime!

## ⌨️ Controls

| Control | Action |
|---|---|
| <kbd>Space</kbd> / <kbd>W</kbd> / <kbd>↑</kbd> | Jump / Thrust (Ship) / Dive (Wave) |
| Left Click / Screen Tap | Jump (Mobile, iPad, PC) |
| <kbd>P</kbd> | Toggle Practice Mode |
| <kbd>Z</kbd> | Place Practice Checkpoint |
| <kbd>X</kbd> | Remove Last Checkpoint |
| <kbd>R</kbd> | Quick Restart Track |
| <kbd>M</kbd> | Mute / Unmute Audio |
